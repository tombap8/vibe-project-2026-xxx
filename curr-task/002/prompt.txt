[ 두번째, 세번째 파트 프롬프트 ]
- 첨부:
(1) 데스크탑 화면
(2) 모바일 화면
- 프롬프트:
첫번째 페이지와 동일한 전체 화면을 채우는 박스를
만들고 제공한 화면과 같이 main>section을 구성하여
두번째, 세번째 페이지를 생성한다.
상단 메뉴등 고정요소는 그대로 두고
별도의 박스로 구성된 새로운 요소만 구현한다.
첫번째 창에서 스크롤시 자동으로 스크롤되어
화면이 하단의 박스로 이동된다. 세번째 페이지도
동일하게 스크롤할때 한페이지만 이동된다.
단, 오른쪽 인디케이터가 흰색으로 현재 위치를 알려준다. 올린 이미지를 분석하여 정확한 요구사항을 반영한다.

[ 검색버튼 클릭시 검색 UI 만들기 프롬프트 ]
- 첨부 : 검색 UI 화면
- 프롬프트 : 
올린 이미지는 상단메뉴의 검색아이콘(돋보기)을 클릭했을때 나오는 화면이야. 기존 화면의 보이는 전체를
덮고 나올 수 있게 fixed 적용해. 검색기능은 아직 넣지마. 검색제시어, 최근 검색어는 화면에 제시된 것만
보이게해. 하단에 상품소개 카드블록과 하단 파트는 동일하게 구현해. 검색어 입력과 닫기 버튼이 있는 상단라인은 고정되어 있고 하단부분은 모두 스크롤 될 수 있게 처리해. 사용된 이미지는 images폴더에 조회하여 경로를 생성해.
