## 히어로 섹션 반응형 웹 구현

첨부한 이미지 2장은 순서대로 데스크탑과 모바일 화면입니다. 두 이미지를 분석하여 레이아웃, 요소 배치, 크기, 간격, 타이포그래피를 최대한 유사하게 구현해 주세요.
실제로 사용된 이미지는 images/used 폴더에 있는 이미지를 사용해주세요.

### 1. 기본 레이아웃
- 히어로 섹션은 화면 전체를 차지하는 `100vh` 높이로 구성합니다.
- 히어로 배경은 이미지로 처리하며, `background-size: cover`를 기본으로 사용합니다.
- 배경 이미지 위에 왼쪽 하단 기준으로 제목과 설명 텍스트를 배치합니다.
- 텍스트 가독성을 위해 배경 하단에 자연스러운 어두운 그라데이션을 적용합니다.

### 2. 고정 UI 요소
- 상단 내비게이션은 `position: fixed`로 화면 상단에 고정합니다.
- 오른쪽 중앙의 세로 슬라이드 인디케이터도 화면에 고정합니다.
- 오른쪽 하단의 원형 플로팅 버튼 2개 역시 화면에 고정합니다.
- 고정 요소들은 히어로 배경과 독립적으로 배치하고 적절한 `z-index`를 적용합니다.

### 3. 반응형 레이아웃
- **Desktop First** 방식으로 작성합니다.
- 데스크탑: 769px 이상
- 모바일: 768px 이하 (`@media (max-width: 768px)`)
- 화면 크기에 따라 단순 축소하지 않고, 참조 이미지에 맞게 요소 배치와 구성을 변경합니다.

### 4. 모바일 전환
- 데스크탑의 로고 및 우측 유틸리티 메뉴는 숨기고, 상단에는 카테고리 메뉴만 표시합니다.
- 카테고리 메뉴는 상단 가로 정렬을 유지합니다.
- 화면 하단에 모바일 전용 고정 내비게이션 바(카테고리, 검색, 홈, 장바구니, 마이)를 표시합니다.
- 히어로 배경은 모바일 전용 이미지를 사용하며, 인물 중심으로 화면을 채웁니다.
- 제목과 설명은 모바일 화면의 왼쪽 하단에 맞춰 재배치하고 크기를 조정합니다.
- 오른쪽 슬라이드 인디케이터와 플로팅 버튼은 유지하되, 모바일 화면에 맞게 위치와 크기를 조정합니다.
- 텍스트와 플로팅 버튼이 하단 내비게이션에 가려지지 않도록 배치합니다.

### 5. 구현 조건
- CSS는 Desktop First 방식의 `max-width` 미디어쿼리를 사용합니다.
- 데스크탑과 모바일 배경 이미지는 별도로 지정할 수 있도록 구성합니다.
- 고정 UI와 히어로 콘텐츠를 구조적으로 분리합니다.
- 아이콘은 가능한 SVG 또는 아이콘 라이브러리를 사용합니다.
- 가로 스크롤이 발생하지 않도록 처리합니다.
- HTML, CSS, JavaScript를 역할에 맞게 분리하고 기존 프로젝트의 코드 구조와 명명 규칙을 유지합니다.

## 전체 메뉴(Full Menu) 반응형 구현
첨부한 이미지 2장은 순서대로 모바일과 데스크탑에서 햄버거 버튼을 클릭했을 때 나타나는 전체 메뉴 화면입니다.

두 이미지를 분석하여 메뉴의 구조, 카테고리 배치, 상품 이미지, 간격, 정렬 및 반응형 레이아웃을 구현해 주세요.
상세 이미지는 images/menu폴더를 참조하고 없는 경우엔 기존 이미지를 재활용하세요

### 1. 공통 동작

- 햄버거 버튼 클릭 시 전체 메뉴가 열립니다.
- X 버튼 클릭 시 메뉴가 닫힙니다.
- 메뉴가 열려 있는 동안 배경 페이지의 스크롤을 방지합니다.
- 메뉴 내부 콘텐츠는 독립적으로 세로 스크롤할 수 있습니다.
- 상단 분류 탭(여성, 남성, 신발, 용품, 키즈, 아울렛)은 메뉴 내부 콘텐츠를 스크롤해도 상단에 고정되도록 `position: sticky`를 적용합니다.
- 메뉴의 열림/닫힘 상태는 JavaScript로 제어합니다.

### 2. 데스크탑 (769px 이상)

- 햄버거 버튼 클릭 시 메뉴가 `fade-in` 애니메이션으로 나타납니다.
- X 버튼 클릭 시 `fade-out` 애니메이션으로 사라집니다.
- 전체 메뉴는 상단 헤더 아래에 표시하며, 높이는 화면의 약 80%로 설정합니다.
- 메뉴 내부의 콘텐츠가 높이를 초과하면 세로 스크롤이 가능하도록 합니다.
- 스크롤바는 숨기되 마우스 휠 및 트랙패드 스크롤은 정상 동작해야 합니다.
- 카테고리 콘텐츠는 참조 이미지처럼 2열 그리드로 배치합니다.
- 메뉴 하단에는 기존 히어로 화면이 보이도록 구성합니다.

### 3. 모바일 (768px 이하)

- Desktop First 방식으로 `@media (max-width: 768px)`을 적용합니다.
- 화면 하단의 햄버거(카테고리) 버튼 클릭 시 전체 메뉴가 화면 오른쪽 바깥에서 왼쪽으로 슬라이딩하며 나타납니다.
- X 버튼 클릭 시 메뉴가 다시 오른쪽 화면 바깥으로 슬라이딩하며 사라집니다.
- 애니메이션은 `transform: translateX()`와 `transition`을 사용합니다.
- 메뉴는 모바일 화면 너비 전체를 차지합니다.
- 메뉴 콘텐츠는 참조 이미지처럼 카테고리별 세로 배치로 전환합니다.
- 상품 목록은 가로 그리드로 구성하고 화면 너비에 따라 자동 줄바꿈되도록 합니다.
- 상단 분류 탭은 스크롤 중에도 고정합니다.
- 모바일 하단 고정 내비게이션은 메뉴가 열려 있는 동안에도 표시하며, 카테고리 버튼은 X(닫기) 버튼으로 전환합니다.
- 하단 고정 내비게이션에 메뉴 콘텐츠가 가려지지 않도록 스크롤 영역 높이를 조정합니다.

### 4. 구현 시 주의사항

- 기존 헤더와 하단 내비게이션 구조를 최대한 유지합니다.
- 데스크탑과 모바일의 메뉴 열림/닫힘 애니메이션을 각각 다르게 적용합니다.
- `overflow-y: auto`를 메뉴 콘텐츠 영역에만 적용하여 고정 UI와 스크롤 영역을 분리합니다.
- `position: sticky`가 정상 동작하도록 스크롤 컨테이너 구조를 구성합니다.
- 메뉴가 닫힐 때 애니메이션이 끝난 후 비활성화하여 즉시 사라지는 현상을 방지합니다.
- `z-index`를 정리하여 메뉴, 헤더, 하단 내비게이션, 플로팅 버튼이 의도한 순서로 표시되도록 합니다.
- 메뉴 내부의 상품 이미지와 텍스트는 제공된 이미지 및 기존 프로젝트 리소스를 최대한 재사용합니다.
