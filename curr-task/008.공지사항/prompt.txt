[ 공지사항 게시판 생성 프롬프트 ]
-첨부: 게시판 각 화면(4가지)
-프롬프트(원본):
첨부된 화면과 동일하게 공지사항 게시판을 만들거야. DB없이 로컬스토리지로 개발할거야. 개발후 파이어베이스 DB로 마이그레이션 할 예정이야. 따라서 localstorage_to_firebase_guidelines.md 파일 지침에 따라 개발 구현해야해.

-프롬프트(수정:클로드)
첨부한 4개 화면(공지사항 목록 / 상세보기 / 글쓰기 / 글수정)과 동일한 UI와 동작으로 공지사항 게시판을 개발해줘.

[개발 조건]
- DB 없이 localStorage로 데이터를 저장한다.
- 개발 후 Firebase(Firestore)로 마이그레이션할 예정이므로, 반드시 localstorage_to_firebase_guidelines.md의 지침을 따라 구현한다.
- 지침의 핵심 원칙(데이터 접근 로직을 별도 Repository/Service 계층으로 분리, 비동기(async/await) 인터페이스, 문서형 데이터 구조, 고유 ID 사용, 날짜는 ISO 문자열 저장)을 지침 파일 내용과 충돌하지 않는 범위에서 지킨다. 충돌 시 지침 파일이 우선한다.
- UI 컴포넌트는 저장소 구현을 직접 호출하지 않고 Repository 인터페이스만 사용한다. (저장소 교체 시 UI 수정이 없어야 함)

[화면별 요구사항]
1. 목록: 총 건수, 분류(전체 등) 선택 + 검색, 글쓰기 버튼, 번호/제목/등록일/조회수 표, 중요공지 상단 고정(핀 아이콘·배경 강조), 최근 글 NEW 뱃지, 페이지네이션(이전/다음 포함)
2. 상세: 중요/유형 뱃지, 제목, 등록일, 조회수, 본문(서식·링크 표시), 첨부파일 다운로드, 이전글/다음글 이동, 목록으로/수정/삭제 버튼(삭제 시 확인창), 진입 시 조회수 +1
3. 글쓰기: 제목(필수), 공지유형 라디오(일반공지/이벤트안내/시스템점검/기타), 첨부파일(최대 10MB, JPG/PNG/PDF/ZIP, 최대 5개), 리치 텍스트 에디터(굵게·기울임·밑줄·취소선·글자색·배경색·정렬·목록·링크·이미지·표·서식제거·전체화면), 글자수 카운터(0/5,000), 필수값 검증 후 등록
4. 글수정: 기존 데이터 불러와 채움, 첨부파일 변경/삭제, "수정일을 현재 날짜로 갱신" 체크박스, 목록으로/취소/수정완료 버튼

[기타]
- 헤더·푸터·브레드크럼 등 공통 레이아웃은 첨부 이미지와 같이 구성한다.
- 초기 확인용 샘플 데이터(이미지 속 목록 기준)를 시드로 제공한다.
- 첨부파일은 localStorage 용량 한계를 고려해 파일 메타데이터 중심으로 저장하고, Firebase Storage 전환 지점을 주석으로 표시한다.
- 구현 완료 후, 지침 준수 여부와 Firebase 전환 시 교체해야 할 파일/함수 목록을 간단히 정리해 알려준다.



[추가수정]

1.공지 게시판 리스트의 타이틀이 중앙정렬이 아니야. 수정필요해. 그리고 글쓰기에서 공지유형 선택 파트에 선택 버튼이 이상한 곳에 가있어. 수정해.

2.공지사항 전체 제목이 모든 화면에서 왼쪽에 있어. 중앙으로 수정해. 그리고 공지사항 리스트에 마우스 오버시 #ccc색으로 배경색 변경해.

3.[ 공지사항 구현후 연계 수정하기 ]
- 공지사항 게시글 중 상위 3개 게시물을 별도의 박스로 구성하여 사이트 상단에 고정하고 한줄 출력하기.내용은 3개의 게시물이 순서대로 넘어감 (멈춤,플레이,닫기버튼 포함)

변경요청
- index페이지 전용 기능이야. notice에서는 제거하고 index에만 표시해. 공지 출력 내용은 박스 중앙에 정렬하고, 닫기버튼 등 컨트롤 파트는 오른쪽에 정렬해.
- 공지 박스는 index페이지 메뉴보다 위 최상단에 표시하고, 닫으면 메뉴가 다시 최상단으로 올라오게 해.
- 상단 Notice 박스의 배경은 #222, 글자는 흰색으로 하고 왼쪽 Notice 라벨은 핑크색 라운드 버튼처럼 표시해. 멈춤 컨트롤은 네모난 모양으로 변경해.
- Notice 박스를 body 바로 아래 문서 흐름에 두어 메뉴와 아래 전체 콘텐츠를 밀어내고, 닫을 때 전체 콘텐츠가 함께 위로 올라오게 해.
- Notice를 닫은 뒤 원래 스크롤 위치와 메뉴 상단에 공백이 남지 않도록 박스 높이만큼 스크롤 위치를 보정해.
- Notice를 닫지 않고 사용자가 스크롤하면 Notice를 자동으로 닫아 위쪽 공간이 남지 않게 해.

-그리고 좀 전에 만든 index페이지 상단 출력은 최상단을 말한거야. 메뉴보다 위에 출력되게해. 닫으면 메뉴는 최상단으로 올라가야겠지.

-수정 : Notice를 닫으면 원래대로 메뉴가 상단에 원래위치로 고정돼야해. 지금은 상단에 공백이 생겨

- 수정 : Notice 를 닫지않고 스크롤하면 위에 공간이 남아. 그럴경우엔 자동으로 닫아줘
